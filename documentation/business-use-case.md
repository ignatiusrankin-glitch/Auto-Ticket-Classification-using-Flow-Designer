# Business Use Case

## Project Title
Auto Ticket Classification Using Flow Designer

## Business Problem

IT support teams receive a large number of tickets from users. Manually
classifying each ticket into the appropriate Category and Subcategory
takes time and can lead to inconsistent classification.

The proposed ServiceNow solution automates ticket classification using
Flow Designer.

## Business Requirements

The system must:

1. Automatically classify IT tickets based on the issue description.

2. Assign both Category and Subcategory without manual intervention.

3. Support dependent choice logic between Category and Subcategory.

4. Send an automated email notification to the caller upon ticket creation.

5. Store ticket information in a structured and standardized format.

6. Ensure easy maintenance and future scalability.

## Expected Outcome

When a new IT ticket is created, the system should automatically process
the ticket information, determine the appropriate Category and
Subcategory, and notify the caller through email.

This reduces manual effort, improves classification consistency, and
provides a scalable approach for managing IT support tickets.

## Technology

- ServiceNow
- Flow Designer
- Custom Table
- Choice Fields
- Email Notifications
- Update Sets
